# TradingAgents upstream changelog

Dependency cleanup removes unused direct dependencies and regenerates the lockfile and third-party notices without adopting upstream's Python/pandas upgrades. Tests default to offline execution; explicitly marked external-service tests require `pytest -m integration`.

Local review fixes also update frontend security patches for Next.js, sharp, DiceBear, and nanoid. The Tailwind typography plugin is a build-time dependency: it runs in the Tailwind configuration and emits static CSS. The production audit gate remains unchanged; development-tool advisories remain outside that release gate, including braces with no patched release.

Historical safeguards reduce look-ahead risk but do not reconstruct unavailable filing vintages. A withheld historical report is not a complete historical financial dataset. This synchronization does not add SEC EDGAR, FRED, Polymarket, new provider families, portfolio analysis, or the upstream backtest engine.
