# Support

Use GitHub Issues for reproducible bugs and focused feature requests. Before filing, search existing issues and include the Evidence Loom version, operating system, runtime mode, relevant redacted logs, and exact reproduction steps.

The maintainers cannot provide investment advice, validate trading decisions, debug private provider accounts, reimburse API costs, or guarantee support for unofficial binaries and modified forks. Never post API keys, account identifiers, portfolio details, or confidential reports in an issue.

Security reports belong in the private process described in [SECURITY.md](SECURITY.md).
